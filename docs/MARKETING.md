# Marketing

今すぐタイマーのストア訴求、スクリーンショット方針、SNS投稿、動画台本、価格/アイコンAB案を蓄積する場所。現在の作業状態や引き継ぎは `docs/HANDOFF.md` に置く。

## 目的

- ゴールはApp Storeで公開し、継続的に改善して売上を作ること。
- 実装相談でも、初見の伝わり方、ストアCV、レビュー、課金導線、継続利用への影響を同時に見る。
- ここには仮説・施策案・生成物方針を残し、現在の作業状態は `docs/HANDOFF.md` に残す。

## 基本方針

- 日本向けではアプリ名「今すぐタイマー」を主役にする。
- 英語名は **TimerTiles** に決定。日本向けでは前面に出しすぎない。
- 訴求軸は「ウィジェットからワンタップでタイマー開始」「よく使う時間をすぐ起動」「消音/集中モードでも鳴る安心感」。
- iOS 26+ 専用アプリ。ストア説明・スクショ・SNSでは「iOS 26以降対応」を明記し、対象外ユーザーの期待値ズレを防ぐ。
- 絵文字や過剰な装飾は避け、iPhoneユーザー向けに清潔で実用的な見た目にする。
- 「タイマーを開く手間がない」「料理・仮眠・勉強など何度も使う時間をすぐ始められる」を短く伝える。
- AlarmKitの強みは安心材料として使うが、過度に専門用語化しない。

## 英語名 / ASOメモ

英語名は **TimerTiles** に決定。タイル状のプリセットUIとタイマー用途が伝わり、短く覚えやすい。英語ストア表記は `TimerTiles: Widget Timer` を基本にする。

過去候補:
- ReadyTimer / QuickTimer / Preset Timer / LaunchTimer / TapTimer / Instant Timer / TimerDeck / TimeTiles

名前変更前に App Store 検索、商標、競合アプリ名、サブタイトルとの重複を確認する。

### 日本語キーワード候補

2026-07-06 時点の見直し候補。タイトル/サブタイトルに含まれる可能性が高い `タイマー` / `ウィジェット` は重複を避け、利用シーン語を中心に寄せる。`目覚まし` は期待値ズレ（目覚まし時計アプリとして探すユーザー）による低評価リスクがあるため外す方針。

推奨候補（95文字）:

```text
料理,キッチン,カップ麺,ラーメン,勉強,集中,仮眠,昼寝,筋トレ,HIIT,インターバル,ポモドーロ,家事,洗濯,瞑想,受験,休憩,作業,仕事,読書,運動,通知,アラーム,習慣,複数,同時
```

外す/弱める候補:
- `ウィジェット`: タイトル/サブタイトル側にあるならキーワード枠では重複。
- `目覚まし`: 価値と期待値がズレやすい。
- `湯沸かし`: 検索語としては弱め。料理/キッチン/カップ麺の方を優先。

## ストアスクリーンショット

- 素材: `assets/screenshot/*.PNG`
- 出力先: `output/store/`
- 基本サイズ: 1290x2796 PNG
- 生成: Codex Desktop の `$imagegen`（`gpt-image-2`）を使う。
- 日本向け1枚目の主訴求: 「ウィジェットからワンタップでタイマー開始」
- ストア画像の注記や説明文で「iOS 26以降対応」を自然に入れる。主訴求より目立たせすぎないが、対象OSは分かるようにする。
- 実機スクショのUIは自然に見せ、内容を過度に改変しない。
- 画像生成だけで作った1枚絵は、文字・アイコン・スクショ細部がボケて汚く見えやすい。最終素材は、実スクショ（`assets/screenshot/framed-screenshots/*.png`）と実フォントで再構成する。
- 生成AIには構図案を作らせ、最終版はローカル合成で文字と端末画面をシャープに保つ。
- ロック画面ウィジェットの強調画像: `assets/screenshot/framed-screenshots/IMG_4194_framed_highlight.png`。枠の見え方は調整中。背景暗幕は使わず、発光リング/細枠で自然に目立たせる方向。
- 作業中の再構成版: `output/store/appstore-preview-clean-01.png`。ChatGPT生成画像のボケ対策として、本物のフレーム付きスクショと Noto Sans CJK のテキスト描画で作ったもの。

## リリース初動方針

- 現在はApp Store公開済み。公開後改善フェーズ。2026-07-06 時点では `1.0.2` 向け TestFlight workflow の完了確認と、必要に応じた手動アップデート申請が次アクション。
- 英語名は TimerTiles に変更済み。App Store Connect 側の英語タイトル/説明/キーワード/スクショ文言は、公開後も最新訴求とずれていないか確認する。
- 初回リリースはユーザーが手動で実施済み。今後は公開後24〜72時間の反応を見ながら、TikTok/X投稿、LP導線、ストア文言、レビュー獲得を優先する。
- TikTokプロフィールにはApp Store直リンクではなく、GitHub Pagesの専用LP `docs/tiktok/index.html` を挟む。公開後URLは `https://sknk-aaa.github.io/widget-timer/tiktok/`。
- TikTokはフォロワー約1200人。これまで作ってきたアプリの作り方や個人開発の過程を簡単に解説するアカウント。
- Xはフォロワー約1500人。個人開発者としての人格で発信している。
- TikTokでは「個人開発でこういうアプリを作った」文脈、Xでは個人開発者としての公開報告・開発背景・使いどころを出す。
- まず見るべきものは、TikTokプロフィールLPのクリック導線、App Storeページ到達後の反応、X/TikTok投稿への反応、レビュー/不具合報告。次に作るべきものは、追加投稿、使い方ショート動画、レビュー依頼の自然な導線。
